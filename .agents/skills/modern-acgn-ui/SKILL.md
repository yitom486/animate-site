# 现代二次元资讯与番组媒体设计规范 (Modern ACGN Media Design)

本技能专为**现代二次元资讯门户、番组索引、追番日历与动漫媒体平台**制定。核心目标是创造具有**高美学辨识度、现代流线感与强烈交互反馈**的 ACGN 体验，彻底摒弃老旧日本网站的拥挤沉闷，同时拒绝千篇一律的通用 AI 模板感与冰冷的 B2B SaaS 风格。

---

## 一、 对标与美学方向

### 1. 现代优秀二次元产品的参考范式

- **AniList / Anime Trending / 现代 Bilibili 番剧 Web**：
  - **海报第一（Poster-First）**：封面立绘是页面的视觉重心与情感触点，UI 组件作为优雅的承托底座。
  - **沉浸式 Hero**：大画幅背景弥散虚化（Ambient Backdrop Blur）、自然暗角过渡，确保前景文字与追番操作对比清晰。
  - **胶囊化元数据（Capsule Metadata）**：将传统表格解构为微质感标签（季度、集数、放送状态、评分）。
  - **卡片呼吸感**：宽裕舒适的内间距，结合柔和圆角（`rounded-xl` / `rounded-2xl`），拒绝密不透风的纯文本排布。

### 2. 严厉禁止：典型老式日本网站特征 (Anti-Retro-Japanese-Web)

- ❌ **绝对禁止“纯文本超链接瀑布”**：如 2000 年代 Yahoo Japan、2ch 式的密集 10px/12px 小字堆叠。
- ❌ **绝对禁止“Excel 嵌套表格地狱 (Table Soup)”**：严禁把声优、制作人员、放送局用灰色网格密密麻麻画成大型数据报表。
- ❌ **绝对禁止视觉噪点**：禁止低画质闪烁 GIF、高对比度荧光边框、走马灯文字、无层级的密铺色块。
- ❌ **绝对禁止割裂排版**：中日文字混排必须保持 1.5~1.6 现代行高，字体优先级严谨（无衬线 variable font 优先，字重梯度明确）。

### 3. 拒绝通用 AI 模板味 (Anti-Generic-AI)

- ❌ 禁止千篇一律的紫蓝霓虹渐变、满屏发光浮动粒子（Glow Blobs）。
- ❌ 禁止“居中大 Slogan + 3 张等宽功能卡”的套壳落地页结构。
- ❌ 禁止无信息价值的大写英文副标题与空洞文案（如 `EXPLORE ULTIMATE OTAKU REALM`）。

## 二、 交互感与微动效标准 (High-Touch Micro-Interactions)

现代二次元界面的魅力在于“生动与响应”，操作应有细腻且符合二次元轻快节奏的反馈：

### 1. 媒体卡片动态交互 (Media Card Hover Dynamics)

- **浮起与景深（Lift & Glow）**：卡片悬停时微幅上浮（`hover:-translate-y-1`），阴影从柔和阴影扩散为带微粉色调的悬浮阴影。
- **封面微变焦**：图片包裹容器设置 `overflow-hidden`，悬停时海报实现平滑轻微放大（`group-hover:scale-105 transition-transform duration-300 ease-out`）。
- **快速动作唤出（Quick Actions Overlay）**：悬停或长按时以轻柔遮罩浮现快捷追番按钮（想看/在看/收藏）与评分快捷入口。

### 2. 状态反馈与生动细节 (Lively Status Details)

- **放送状态呼吸灯**：
  - “今日放送中 / 连载中”：配合微型脉冲点（`animate-pulse`），给予追番者即时感。
- **评分徽章设计**：
  - 评分数值使用等宽或清晰数字字体（JetBrains Mono / Geist），配合温润金色/粉色微透明背景（如 `bg-amber-500/10 text-amber-600 dark:text-amber-400`）。
- **放送周历 Tab 滑动**：
  - “周一至周日”追番排期切换时，高亮指示器平滑滑移，避免生硬跳变。

### 3. 全局转场与动画尊重

- **View Transitions 强制执行**：亮暗主题切换、重大视角切换（如大图流与列表流切换）调用 `document.startViewTransition`。
- **无障碍保障**：所有弹性动效严格包裹在 `motion-reduce:transition-none` / `motion-reduce:transform-none` 下。

## 三、 亚域空间粉色调主题融合 (Brand Palette Integration)

严格遵循本项目的淡粉色品牌规范，让二次元的温暖浪漫与高对比度易读性统一：

| 主题模式         | 背景与表面 Token                                                                                          | 强调色与文字 Token                                                                                   | 视觉感受                             |
| :--------------- | :-------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------- | :----------------------------------- |
| **亮色 (Light)** | `bg-background` (柔和淡粉 `oklch(0.982 0.006 350)`)<br>`bg-card` (纯净微粉白 `oklch(0.997 0.002 350)`)    | `bg-primary` / `text-primary` (深粉高对比 `oklch(0.48 0.105 355)`)<br>`text-foreground` (柔和深灰粉) | 樱花轻暖质感、清爽通透、高阅读对比度 |
| **暗色 (Dark)**  | `bg-background` (微粉调深炭灰 `oklch(0.17 0.009 330)`)<br>`bg-card` (深灰粉表面 `oklch(0.215 0.011 330)`) | `bg-primary` (柔粉荧光高光 `oklch(0.81 0.065 350)`)<br>`text-primary-foreground` (暗部反色)          | 沉浸式夜间追番、不刺眼、粉调微光轮廓 |

- **语义色唯一性**：严禁硬编码任何十六进制颜色或通用 Tailwind 原始色（如 `text-pink-500`、`bg-gray-900`），必须使用语义类（`bg-card`、`text-foreground`、`text-muted-foreground`、`border-border`）。

## 四、 核心二次元组件交互模式

### 1. 放送周历矩阵 (Broadcast Schedule)

- 顶部为横向周一至周日切换栏，当天带有醒目的“TODAY / 今日”高光微徽章。
- 卡片展示：海报封面 + 放送时间（如 `23:30 (JST)` / 本地换算）+ 更新至第几话 + 独播/播放源小图标。

### 2. 番剧海报网格 (Anime Poster Grid)

- 比例建议：海报固定 `aspect-[3/4]` 或 `aspect-[2/3]`。
- 底部内嵌半透明渐变遮罩压暗（`bg-gradient-to-t from-black/70 via-black/20 to-transparent`），叠放剧名与评分，保证不同图片背景下文字绝对清晰。
- 封面加载采用骨架屏微弱呼吸波纹（`bg-muted animate-pulse`），图片 `loading="lazy"` 并配合自然渐显。

### 3. 声优与制作人员 (Staff & Cast Micro-Cards)

- 废弃死板表格，采用头像圆形徽章（`rounded-full`）搭配“声优名 × 角色名”并排微卡，悬停可轻浮展开角色立绘缩略图。

## 五、 交付前自检清单 (ACGN Design Checklist)

每次完成二次元页面或组件时，核对以下 5 项：

1. **老式日系检查**：是否存在密不透风的小字纯链接或 Excel 灰框表格？若有，立刻改为胶囊标签与现代网格。
2. **AI 模板检查**：是否存在多余的紫蓝光晕、假大空居中口号？若有，立即剥离。
3. **视觉第一性**：海报、封面图是否处于视觉第一动线？文字对比度在图上图下是否均清晰？
4. **微动效与触感**：卡片悬停是否有顺滑的 `hover:-translate-y-1`、图片平滑变焦与状态反馈？
5. **主题色彩合规**：是否全量基于项目 CSS 变量与 Tailwind 语义 Token，亮暗切换是否自然顺畅？
